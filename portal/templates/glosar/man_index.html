Manualul C (man pages)

Paginile de manual din Linux (man-pages, în engleză) pentru funcțiile, fișierele antet și uneltele folosite la curs. Sunt aceleași pagini pe care le deschizi în terminal cu man 3 printf. Identificatorii C din text sunt legați de conceptele cursului. Ghidul Citirea documentației explică cum să citești o pagină de manual.

Cum citești o pagină de manual: începe cu SYNOPSIS (ce #include îți trebuie și semnătura), apoi RETURN VALUE (ce întoarce funcția și cum semnalează erorile), apoi DESCRIPTION. Secțiunea EXAMPLES are adesea un program complet.
